# Arex388.HdFleet

A highly opinionated .NET Standard 2.0 client library for the [HD Fleet](https://www.hdfleet.com) Integrations External API v1 (GPS fleet tracking). Single-account consumers inject `IHdFleetClient`; multi-account consumers inject `IHdFleetClientFactory` and create one client per account key.
